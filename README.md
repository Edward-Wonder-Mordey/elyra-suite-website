# Elyra Suite

Official website for **Elyra Suite** — **Beauty • Business • Excellence**.

The website presents Elyra Suite's beauty, bridal and events, store, administrative support, business support, social media, Academy and consulting capabilities.

## Live website

Current GitHub Pages address:

`https://edward-wonder-mordey.github.io/elyra-suite-website/`

## Public configuration

Browser-safe settings are kept in `site-config.js`:

- site base URL
- Google Analytics Measurement ID (blank until a real ID is supplied)
- Eragonova Enterprise strategic-partner URL
- official social-media URLs when confirmed

**Never place passwords, service-role keys, private API keys or other secrets in `site-config.js` or any other browser-delivered file.**

## Main routes

The site currently uses hash routes, including:

`#/home`, `#/about`, `#/beauty`, `#/bridal`, `#/business`, `#/academy`, `#/shop`, `#/social`, `#/consulting`, `#/portfolio`, `#/resources`, `#/partners`, `#/portal`, `#/contact`, `#/privacy`, `#/terms`, `#/bookingpolicy`, and `#/returnspolicy`.
